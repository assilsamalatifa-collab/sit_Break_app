# تطبيق تذكير الجلوس والاستراحة

نموذج أولي (Prototype) بـ Flutter يعمل على Android و iOS من نفس الكود.

## طريقة التشغيل

1. ثبّت Flutter SDK: https://flutter.dev
2. من داخل مجلد المشروع:
   ```
   flutter pub get
   flutter run
   ```
3. لبناء نسخة Android:
   ```
   flutter build apk --release
   ```
4. لبناء نسخة iOS (يتطلب جهاز Mac و Xcode):
   ```
   flutter build ios --release
   ```

## كيف يعمل الكشف حالياً

- يقرأ حساس التسارع (accelerometer) باستمرار.
- يحسب متوسط "التذبذب" خلال آخر ثوانٍ.
- إذا كان الجهاز ثابتاً بشكل مستمر (8 ثوانٍ) → يبدأ عد الجلوس.
- إذا صارت حركة واضحة مستمرة (5 ثوانٍ) أثناء الجلوس → يعتبر أنك قمت، ويوقف العداد.
- عند انتهاء مدة الجلوس → إشعار يطلب استراحة، ثم عداد الاستراحة.
- عند انتهاء الاستراحة → إشعار بالرجوع للجلسة.

يمكنك تعديل حساسية الكشف من المتغير `_stillnessThreshold` في `lib/main.dart`
(كلما قل الرقم، زادت الحساسية للحركة).

## القيود المهمة (اقرأها قبل الاعتماد على التطبيق)

1. **الدقة**: الحساس يكتشف "ثبات الجهاز" وليس "جلوسك أنت". لو تركت الجوال
   على الطاولة ووقفت، قد يستمر بعدّ "جلوس".
2. **المراقبة بالخلفية على iOS**: أبل تحد بشدة من قراءة الحساسات لما
   يكون التطبيق مغلقاً/بالخلفية. هذا النموذج يعمل بشكل موثوق فقط والتطبيق
   مفتوح على الشاشة. لتفعيل مراقبة حقيقية بالخلفية على iOS تحتاج
   استخدام `Core Motion` مع background modes خاصة، وهذا معقد وله حدود
   من نظام التشغيل نفسه.
3. **المراقبة بالخلفية على Android**: ممكنة وأكثر مرونة، لكن تحتاج
   إضافة "foreground service" (مثلاً عبر حزمة `flutter_background_service`)
   حتى يستمر التطبيق يقرأ الحساس والنظام لا يوقفه لتوفير البطارية.
4. **بديل أدق بكثير**: لو تبي دقة حقيقية لمعرفة أنك جالس فعلاً، الحل
   الأفضل هو دمج مع ساعة ذكية (Apple Watch / Wear OS) التي تلبس على
   الجسم مباشرة وتفرق بين الجلوس والوقوف والمشي بدقة عالية.

## خطوات مقترحة لاحقاً

- إضافة حفظ الإعدادات محلياً (`shared_preferences`).
- إضافة إحصائيات يومية (عدد مرات الجلوس، إجمالي وقت الجلوس).
- إضافة خدمة خلفية لأندرويد.
- تجربة القيم (`_confirmStillFor`, `_confirmMovingFor`, `_stillnessThreshold`)
  والتعديل حسب استخدامك الفعلي.
